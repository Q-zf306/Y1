# 生日蛋糕成型 · 微缩三维场景 🎂✨

> 一个可以自由拖拽、旋转、缩放观看的"巨型蛋糕成型"小场景。
> 三层蛋糕从散件一步步组装：蛋糕胚坠落叠起 → 奶油浇淋 → 草莓与裱花落位 →
> 蜡烛点燃 → 转台缓缓自转，八音盒版《祝你生日快乐》循环响起，
> 夜空中不时有流星拖着长尾划过。三渲二（Cel-Shading）日式动画风格，无任何 UI。

## ✨ 特点

- **单文件、零依赖**：Three.js 已完整打包进 HTML，无需联网，手机 / 微信内置浏览器都能打开
- **成型动画**：约 13 秒的组装演出，落地弹跳挤压、淋面流淌、装饰精准落位、烛火摇曳
- **交互**：拖拽环绕旋转、滚轮缩放、右键平移；成型后转台自动缓慢自转
- **音乐**：成型完成后循环播放 WebAudio 实时合成的八音盒版《生日快乐》
  （浏览器禁止网页自动出声，**首次点击场景后**即开始播放）
- **彩蛋参数**：`?instant` 跳过动画直接看成品；`?stage=0.5` 冻结在组装中段；
  `?cam=close / top / low` 预设机位

## 🚀 运行

双击 `index.html` 即可，推荐 Chrome / Edge / Safari 等现代浏览器。

## 📁 上传到 GitHub Pages

1. 仓库根目录放入 `index.html`；
2. Settings → Pages → Source 选 `Deploy from a branch`（main / root）；
3. 一分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

## 🛠️ 技术

- Three.js r160（已内联打包，ES2017 目标 + roundRect 补丁，兼容旧内核）
- MeshToonMaterial 四阶渐变 + 反向壳描边；UnrealBloom 辉光 + ACES 色调映射
- 全部贴图（插牌、木纹年轮、光斑…）Canvas 程序化生成，无外部图片/音频/字体
- 《生日快乐》由 WebAudio 振荡器实时合成（正弦主音 + 3 倍频泛音 + 回声延迟）
